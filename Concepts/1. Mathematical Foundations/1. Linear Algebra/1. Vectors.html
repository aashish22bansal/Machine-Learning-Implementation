Vectors in Linear Algebra

A clear, machine-learning-oriented explanation of vectors — the atomic unit of data and computation.

1. What Is a Vector?

A vector is a mathematical object that has both magnitude and direction. In linear algebra, it is represented as an ordered list of numbers.

v = [ v₁, v₂, v₃, ..., vₙ ]

Each value is called a component of the vector.

In machine learning, every data point is ultimately represented as a vector.

2. Vectors as Data (Machine Learning View)

  • A person → [age, height, weight, income]
  • An image → [pixel₁, pixel₂, ..., pixelₙ]
  • A word embedding → [0.21, -0.03, 0.87, ...]
  • Model weights → parameter vector
ML models learn by transforming vectors into better vectors.

3. Geometric Interpretation

In 2D or 3D, vectors can be visualized as arrows starting at the origin and pointing to a coordinate.

v = (x, y) or v = (x, y, z)

This geometric interpretation helps us understand similarity, distance, and projections.

4. Vector Magnitude (Length)

The magnitude (or length) of a vector tells us how large it is.

||v|| = √(v₁² + v₂² + ... + vₙ²)

Example:

v = (3, 4) → ||v|| = 5
In ML, magnitude affects distance, regularization, and gradient strength.

5. Unit Vectors and Normalization

A unit vector has a magnitude of exactly 1. It keeps direction but removes scale.

v̂ = v / ||v||
  • Makes vectors comparable
  • Improves numerical stability
  • Used in cosine similarity and embeddings
Normalization preserves meaning while removing scale bias.

6. Vector Addition and Subtraction

Vector addition combines directions component-wise.

a + b = (a₁ + b₁, a₂ + b₂, ...)

Subtraction represents movement from one point to another.

Gradient updates in ML are vector additions.

7. Scalar Multiplication

Multiplying a vector by a scalar stretches or shrinks it.

c · v = (c·v₁, c·v₂, ...)
  • c > 1 → stretches
  • 0 < c < 1 → shrinks
  • c < 0 → reverses direction
Learning rate × gradient is scalar multiplication.

8. Dot Product (Most Important)

The dot product measures similarity and projection.

a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
a · b = ||a|| ||b|| cos(θ)
  • Positive → similar direction
  • Zero → perpendicular
  • Negative → opposite direction
Every neuron computes a dot product.

9. Vectors in Machine Learning

ML Concept Vector Role
Dataset row Feature vector
Model parameters Weight vector
Prediction Dot product
Training Vector updates
Embeddings Semantic vectors

10. Key Takeaway

A vector is a container of meaning and direction. Machine learning is the science of transforming vectors intelligently.
